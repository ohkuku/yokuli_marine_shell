# YOKULI OS 品牌资产

2026-09-25 后续用户附件取代此前的独立 Y 标记。唯一编辑母版为 `yokuli-wordmark.svg`：大写 YOKULI 占主位，帆在 O 内，水线连接 O，OS 位于右下角。这里是附件轮廓的平面矢量适配，不包含原图纸纹和光照渐变。

`python3 scripts/generate_brand_assets.py` 生成 12 个生产 VectorDrawable、`yokuli-mark.svg` 和 `yokuli-os.svg`。不要分别编辑生成文件，也不要让旧版生成器重新写回 Y 图形。小尺寸图标只是完整字标中 O、帆和水线的提取，不是另一个独立字母商标。

`YokuliBrandMark` 用于现有小标记入口；`YokuliBrandWordmark` 为完整字标的单色版本；`YokuliBrandSignature` 用于关于页等完整签名位置，不再在左边重复拼标记。安装图标、主题单色图标、系统启动窗口中的标志与上述 Compose 组件使用同一母版。

原附件的纸白、墨色、帆绿、水线和辅助灰保留在 SVG 母版，作为原始品牌依据。2026-09-27 本轮用户进一步要求黑白主调、扁平、极简、文字主导；生产启动图标、通知小图和 Compose 签名采用同一几何的单色版本，OS 小字保留次级灰度。系统默认增加 MONOCHROME，并一次性迁移默认强调色；已有壁纸、透明度、布局及每块磁贴的显式自定义不重置，旧色枚举继续兼容读取。

此轮视觉要求替代此前“只换 Logo、不改主题”的实施范围。控件结构、访问语义、经典 Home 动效和独立警报颜色语义保留；不把品牌绿色套到数据状态，也不在业务页面堆叠品牌标记。
