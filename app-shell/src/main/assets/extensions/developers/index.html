01 / START

一个离线包，两种语言

One offline package, two languages

JavaScript

复制仓库的 sdk/templates/javascript，修改清单与 app.js。无需 npm 或构建框架。

Copy sdk/templates/javascript from the repository. Edit its manifest and app.js. No npm or framework is required.

python3 sdk/tools/package_extensions.py \
  sdk/templates/javascript \
  --output /tmp/myboat.yokuli.zip

Kotlin/JS

复制 sdk/templates/kotlin-js，使用附带的强类型 SDK 声明。Kotlin 2.1.20 编译为 JavaScript；这不是 Android APK、Dex 插件或原生 Compose SDK。

Copy sdk/templates/kotlin-js, including its typed SDK declarations. Kotlin 2.1.20 compiles to JavaScript. This is not an APK, Dex plugin or native Compose SDK.

./gradlew -p sdk/templates/kotlin-js packageYokuli
# build/yokuli/org.example.kotlinboat.yokuli.zip

将生成的 .yokuli.zip 放到手机，在「应用中心 → 安装文件」选择，阅读权限并安装。安装后从应用列表打开；系统返回键负责返回，不在网页内再画一个“回 Yokuli”按钮。

Copy the .yokuli.zip to your phone, choose “App Center → Install file”, review permissions and install. Open it from the app list. Let the system Back key handle navigation; do not add a separate “Back to Yokuli” button.

02 / PACKAGE

清单就是应用的约定

The manifest defines your app

{
  "id": "org.example.myboat",
  "name": "我的船况",
  "nameEn": "My boat",
  "version": 1,
  "description": "查看船速和测量时间。",
  "descriptionEn": "See boat speed and measurement age.",
  "sdk": 1,
  "entry": "index.html",
  "permissions": ["marine.read", "navigation.open"]
}

压缩包根目录必须有 manifest.json 与 index.html。ID 使用反向域名，版本为递增整数。最多 256 个文件、单文件 8 MiB、解压后总计 32 MiB；不能使用符号链接、路径穿越或远程资源。更新包不能通过改名覆盖内置应用。

Include manifest.json and index.html at the archive root. Use a reverse-domain ID and an increasing integer version. Maximum: 256 files, 8 MiB per file, 32 MiB unpacked. No symlinks, path traversal or remote resources. Packages cannot replace built-in apps.

<link rel="stylesheet" href="/_sdk/yokuli.css">
<script src="/_sdk/yokuli.js" defer></script>
<script src="app.js" defer></script>

SDK 由宿主提供，不要复制它进每个包。应用脚本必须是包内独立文件；内联脚本、eval、CDN、外部网络与 Android 原生桥均不可用。

The host supplies the SDK; do not copy it into every package. Scripts must be separate local files. Inline scripts, eval, CDNs, external networking and Android native bridges are unavailable.

读数不是一个裸数值

A reading is more than a number

// snapshot.readings.sog
{
  value, unit,             // user display units
  rawValue, rawUnit,       // canonical physical units
  measuredAt, ageMillis,   // actual measurement time, not polling time
  quality, freshness,
  source: { id, name, type, class, connectionId, generation },
  reference
}

readings 的键：sog 对地速度、cog 航迹向、heading 船首向、depth 水深、tws/twd 真风速/向、aws/awa 视风速/角、pressure 气压、air/water 气温/水温、heel/pitch 横倾/纵倾。snapshotCurrent 表示 Core 投影是否仍当前，snapshotAgeMillis 是投影年龄，不是测量年龄。Core 断线或投影过期时 freshness 降为 STALE，原质量保留在 sourceFreshness。不存在的值为 null；有历史值但过期时保留时间与质量。绝不把 COG 当 Heading，也不因收到快照就把测量时间改成当前时间。

readings keys: sog speed over ground, cog course over ground, heading bow heading, depth, tws/twd true wind speed/direction, aws/awa apparent wind speed/angle, pressure, air/water temperatures, and heel/pitch. snapshotCurrent reports whether the Core projection is current; snapshotAgeMillis measures projection age, not measurement age. Disconnection or an old projection downgrades freshness to STALE while preserving sourceFreshness. Missing values are null. Older readings retain their real time and quality. Never substitute COG for heading or replace measurement time with the snapshot time.

vessel 提供经纬度、来源、测量时间与质量；positionDisplay 采用用户坐标格式。数值使用 value/unit 展示，用 rawValue/rawUnit 运算。不能为了“实时感”自行平滑或补造安全业务数据。

vessel provides position, source, measurement time and quality; positionDisplay follows the user’s coordinate format. Display value/unit; calculate with rawValue/rawUnit. Do not invent or smooth safety data to make it look live.

可打开的目的地：chart、data_center、nmea、ais、voyages、anchor、places、instruments。GPS、NMEA 和来源选择由数据中心管理，小应用不直接开传感器或创建连接。

Allowed destinations: chart, data_center, nmea, ais, voyages, anchor, places, instruments. The system manages GPS, NMEA and source selection. Mini-apps do not activate sensors or create connections.

04 / UI

像 Yokuli 一样简单

Keep it recognisably Yokuli

使用共享的 yk-page、yk-header、yk-section、yk-grid、yk-check。Yokuli.ui.node/button/metric/status 提供安全文本、异步操作状态、真实时间与来源。用文字说明动作，用少量关键数字表达船况。不要再造 Shell 的标题、Home、导航键或通知中心。

Use shared yk-page, yk-header, yk-section, yk-grid and yk-check styles. Yokuli.ui.node/button/metric/status provide safe text, async action states, real measurement ages and sources. Keep a few important readings prominent. Do not recreate the Shell header, Home key or notification center.

const button = Yokuli.ui.button('Chart', () =>
  Yokuli.navigation.open('chart')
);
root.append(button);
root.addEventListener('yokulierror', event => {
  errorPanel.textContent = event.detail.message;
});

组件不拼接业务 HTML，不将错误伪装为成功。按钮等待 Promise 完成，防止连点。异步失败通过 yokulierror 冒泡；你的页面必须展示错误并允许重试。应用内置中文与英文，不把调试术语当用户文案。

Components avoid HTML string interpolation. Buttons wait for returned promises and prevent duplicate taps. Failures bubble as yokulierror; show the error and allow a retry. Provide Chinese and English copy without exposing internal jargon.

05 / TRUST & LIFECYCLE

让系统保持唯一所有者

Keep one owner of system state

  • marine.read：读取用户已选择的规范船舶数据及来源；它不是传感器权限。
  • nmea.read：查看已有 NMEA 连接的状态，不包含写入、转发或操纵自动舵。
  • navigation.open：通过系统打开白名单应用；系统保留返回关系。
  • SDK 存储按应用 ID 隔离；卸载清除小应用与其 SDK 私有数据。内置应用不可卸载。
  • 隐藏页面停止订阅；关闭释放 WebView。不要将守锚、导航、日志收集搬进网页计时器。
  • 无后台服务、文件系统、网络、原生代码执行或自定义来源注册。来源与长期任务仍归 Marine Core。
  • 安装权限不是发布者可信证明。SDK 1 是有限能力的本地包系统，尚无在线商店审核、发布者签名信任链或自动更新。
  • marine.read reads the user’s selected canonical vessel data and provenance; it is not sensor access.
  • nmea.read reads existing connection status. No sending, forwarding or autopilot commands.
  • navigation.open opens allowlisted apps through the Shell and preserves the return path.
  • SDK storage is isolated per application ID. Uninstall removes the mini-app and its private SDK data. Built-in apps cannot be uninstalled.
  • Hidden pages stop polling. Closing releases the WebView. Never move anchor alarms, navigation or recording into a browser timer.
  • No background services, arbitrary files, networking, native code or new source registration. Marine Core owns long-running work.
  • A permission grant is not proof of publisher identity. SDK 1 is a constrained local-package system, without store review, a publisher-signature trust chain or automatic updates.

失败也属于接口

Failure is part of the interface

所有接口返回 Promise。常见错误代码：PERMISSION_DENIED、RATE_LIMITED、SESSION_EXPIRED、STORAGE_FAILURE、INVALID_ARGUMENT、METHOD_NOT_FOUND、NOT_FOREGROUND；传输还可能返回 TIMEOUT、HOST_UNAVAILABLE、CLOSED。Core 重连时展示真实连接状态，不自动重放写操作。快照一秒一次、总体每秒最多 20 次请求，存储写入每秒最多 5 次。单次请求含封装上限 96 KiB，超限返回 PAYLOAD_TOO_LARGE。

APIs return promises. Errors include PERMISSION_DENIED, RATE_LIMITED, SESSION_EXPIRED, STORAGE_FAILURE, INVALID_ARGUMENT, METHOD_NOT_FOUND, NOT_FOREGROUND; transport may return TIMEOUT, HOST_UNAVAILABLE or CLOSED. Show real connection state during Core reconnects. Do not replay writes automatically. Limits: one snapshot per second, 20 total requests per second, five storage writes per second. Requests including the envelope are limited to 96 KiB; larger requests reject with PAYLOAD_TOO_LARGE.
