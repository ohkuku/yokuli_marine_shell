02 / PACKAGE

清单就是应用的约定

The manifest defines your app

{
  "id": "org.example.myboat",
  "name": "我的船况",
  "nameEn": "My boat",
  "version": 1,
  "description": "查看船速和测量时间。",
  "descriptionEn": "See boat speed and measurement age.",
  "sdk": 2,
  "entry": "index.html",
  "permissions": ["marine.read", "navigation.open"]
}

压缩包根目录必须有 manifest.json 与 index.html。ID 使用反向域名，版本为递增整数。安装文件统一使用 .ykl 后缀，内部是 ZIP 容器。清单 SDK 1 仍兼容，系统控制权限需 SDK 2。最多 256 个文件、单文件 8 MiB、解压后总计 32 MiB；不能使用符号链接、路径穿越或远程资源。更新包不能通过改名覆盖内置应用。

Include manifest.json and index.html at the archive root. Use a reverse-domain ID and an increasing integer version. Installable files use .ykl, with ZIP as the internal container. SDK 1 manifests remain compatible; system-control permissions require SDK 2. Maximum: 256 files, 8 MiB per file, 32 MiB unpacked. No symlinks, path traversal or remote resources. Packages cannot replace built-in apps.

<link rel="stylesheet" href="/_sdk/yokuli.css">
<script src="/_sdk/yokuli.js" defer></script>
<script src="app.js" defer></script>

SDK 由宿主提供，不要复制它进每个包。应用脚本必须是包内独立文件；内联脚本、eval、CDN、外部网络与 Android 原生桥均不可用。

The host supplies the SDK; do not copy it into every package. Scripts must be separate local files. Inline scripts, eval, CDNs, external networking and Android native bridges are unavailable.

读数不是一个裸数值

A reading is more than a number

// snapshot.readings.sog
{
  value, unit,             // user display units
  rawValue, rawUnit,       // canonical physical units
  measuredAt, ageMillis,   // actual measurement time, not polling time
  quality, freshness,
  source: { id, name, type, class, connectionId, generation },
  reference
}

readings 的键：sog 对地速度、cog 航迹向、heading 船首向、depth 水深、tws/twd 真风速/向、aws/awa 视风速/角、pressure 气压、air/water 气温/水温、heel/pitch 横倾/纵倾。snapshotCurrent 表示 Core 投影是否仍当前，snapshotAgeMillis 是投影年龄，不是测量年龄。Core 断线或投影过期时 freshness 降为 STALE，原质量保留在 sourceFreshness。不存在的值为 null；有历史值但过期时保留时间与质量。绝不把 COG 当 Heading，也不因收到快照就把测量时间改成当前时间。

readings keys: sog speed over ground, cog course over ground, heading bow heading, depth, tws/twd true wind speed/direction, aws/awa apparent wind speed/angle, pressure, air/water temperatures, and heel/pitch. snapshotCurrent reports whether the Core projection is current; snapshotAgeMillis measures projection age, not measurement age. Disconnection or an old projection downgrades freshness to STALE while preserving sourceFreshness. Missing values are null. Older readings retain their real time and quality. Never substitute COG for heading or replace measurement time with the snapshot time.

vessel 提供经纬度、来源、测量时间与质量；positionDisplay 采用用户坐标格式。数值使用 value/unit 展示，用 rawValue/rawUnit 运算。不能为了“实时感”自行平滑或补造安全业务数据。

vessel provides position, source, measurement time and quality; positionDisplay follows the user’s coordinate format. Display value/unit; calculate with rawValue/rawUnit. Do not invent or smooth safety data to make it look live.

可打开的目的地：chart、data_center、nmea、ais、voyages、anchor、places、instruments、library、local_nmea、settings、app_center。GPS、NMEA 和来源选择由数据中心管理，小应用不直接开传感器或创建连接。

Allowed destinations: chart, data_center, nmea, ais, voyages, anchor, places, instruments, library, local_nmea, settings, app_center. The system manages GPS, NMEA and source selection. Mini-apps do not activate sensors or create connections.

Use shared yk-page, yk-header, yk-section, yk-grid and yk-check styles. Yokuli.ui.node/button/metric/status provide safe text, async action states, real measurement ages and sources. Keep a few important readings prominent. Do not recreate the Shell header, Home key or notification center.

Components avoid HTML string interpolation. Buttons wait for returned promises and prevent duplicate taps. Failures bubble as yokulierror; show the error and allow a retry. Provide Chinese and English copy without exposing internal jargon.

05 / SYSTEM CAPABILITIES · SDK 2

可以控制，但不另起一套系统

Control the system without duplicating it

先调用 Yokuli.system.services()。目录逐项报告方法的 since / permission / declared / granted / available / foregroundOnly；“SDK 有这个方法”“应用请求了权限”“用户已授权”“服务此刻可用”分别判断。控制权限首次安装默认关闭；更新保留原有授权，不会自动开放新增权限。撤权会使运行中句柄失效，重新授权后仍须重新打开应用。目录还报告当前应用 SDK、packageFormat: '.ykl' 和实际运行时能力。

Start with Yokuli.system.services(). Each method reports since / permission / declared / granted / available / foregroundOnly. A supported method, declared permission, user grant and currently available service are different conditions. Control permissions default to off at first install. Updates preserve prior choices and do not auto-grant new permissions. Revocation invalidates running handles; granting again requires reopening the app. The directory also reports the app SDK, packageFormat: '.ykl' and actual runtime capabilities.

设备是系统的投影

Devices reflect the real system

devices.snapshot() 返回 {connection,ready,runtimeId,revision,capturedElapsedMillis,ageMillis,devices,error}。每台设备有 id/name/kind/backend/availability/health/requested/active/generation/generationOrigin/capabilities，并保留 provenance.driver/sourceId/connectionId 与测量、接收、输出的单调时刻。不把请求启用当作运行，不把查询时间当作测量时间。

Each device includes id/name/kind/backend/availability/health/requested/active/generation/generationOrigin/capabilities, provenance.driver/sourceId/connectionId and monotonic measurement, receive and output times. Requested is not active; query time is not measurement time.

记录操作必须等回执

Recording commands need receipts

const command = {
  action: 'pause',
  requestId: 'myapp_' + crypto.randomUUID().replaceAll('-', ''),
  sessionId: current.sessionId
};
// Persist command with storage.set before sending.
const result = await Yokuli.voyage.command(command);
// CONFIRMED is success. QUEUED / EXECUTING / UNKNOWN are not.
const checked = await Yokuli.voyage.receipt(command.requestId, true);
// Retry with the same complete payload and requestId, never a new ID.

requestId 为 1–80 位字母、数字、下划线或连字符。除 start 外必须提供十进制字符串 sessionId（不要转为 JavaScript Number）；name 最多 80 字。回执状态为 QUEUED / EXECUTING / UNKNOWN / CONFIRMED / REJECTED / FAILED，后三种 terminal=true，只有 CONFIRMED 是成功。超时不能自动换 ID 重做。相同 ID 改变动作、会话或参数会返回 REQUEST_ID_CONFLICT。请先持久保存待处理命令，重开应用后继续查同一回执。

requestId contains 1–80 letters, digits, underscores or hyphens. All commands except start require sessionId as a decimal string (do not convert it to a JavaScript Number); name is limited to 80 characters. Receipts are QUEUED / EXECUTING / UNKNOWN / CONFIRMED / REJECTED / FAILED. The last three are terminal; only CONFIRMED means success. A timeout is not permission to retry with a new ID. Changing a command’s payload under the same ID produces REQUEST_ID_CONFLICT. Persist pending commands and reconcile after reopening.

所有 watch 都在页面隐藏或宿主暂停时停下，显示后继续，返回 stop 函数。控制方法只在前台可用。SDK 2 仍没有虚拟时钟、系统级录制回放、场景引擎、第三方驱动/HAL、任意后台脚本或 APK 执行；当前设备后端只有 REAL。不能把这些已接入的服务描述成完整虚拟机。

Every watch pauses when hidden or suspended by the host, resumes when visible, and returns a stop function. Control methods require the foreground. SDK 2 still has no virtual clock, system replay, scenario engine, third-party drivers/HAL, arbitrary background scripts or APK execution. REAL is the only device backend. These connected services are not a complete virtual machine.

06 / TRUST & LIFECYCLE

让系统保持唯一所有者

Keep one owner of system state

  • marine.read：读取用户已选择的规范船舶数据及来源；它不是传感器权限。
  • nmea.read 读取连接状态；nmea.control 启停用户已维护的连接，收发仍遵守 Core 的原有配置与防环路规则。不能发送任意句子或操纵自动舵。
  • navigation.open：通过系统打开白名单应用；系统保留返回关系。
  • SDK 存储按应用 ID 隔离；卸载清除小应用与其 SDK 私有数据。内置应用不可卸载。
  • 隐藏页面停止订阅；关闭释放 WebView。不要将守锚、导航、日志收集搬进网页计时器。
  • 没有任意后台脚本、文件系统、原始网络、原生代码执行或自定义来源注册。SDK 2 的选择来源、启停连接、分享和航行记录均进入 Marine Core 的既有服务。
  • 安装权限不是发布者可信证明。SDK 2 是有限能力的本地包系统，尚无在线商店审核、发布者签名信任链或自动更新。
  • marine.read reads the user’s selected canonical vessel data and provenance; it is not sensor access.
  • nmea.read reads connection status; nmea.control enables or disables existing user-configured connections. Core retains its routing and loop-prevention rules. No arbitrary sentences or autopilot commands.
  • navigation.open opens allowlisted apps through the Shell and preserves the return path.
  • SDK storage is isolated per application ID. Uninstall removes the mini-app and its private SDK data. Built-in apps cannot be uninstalled.
  • Hidden pages stop polling. Closing releases the WebView. Never move anchor alarms, navigation or recording into a browser timer.
  • No arbitrary background scripts, files, raw networking, native code or new source registration. SDK 2 source selection, connection controls, sharing and voyage recording call existing Marine Core services.
  • A permission grant is not proof of publisher identity. SDK 2 is a constrained local-package system, without store review, a publisher-signature trust chain or automatic updates.

失败也属于接口

Failure is part of the interface

所有接口返回 Promise。常见错误代码：PERMISSION_DENIED、RATE_LIMITED、SESSION_EXPIRED、STORAGE_FAILURE、INVALID_ARGUMENT、METHOD_NOT_FOUND、NOT_FOREGROUND；传输还可能返回 TIMEOUT、HOST_UNAVAILABLE、CLOSED。Core 重连时展示真实连接状态，不自动重放写操作。marine.snapshot 每秒一次、总体每秒最多 20 次请求，存储与系统控制共用每秒 5 次的写入额度。单次请求含封装上限 96 KiB，超限返回 PAYLOAD_TOO_LARGE。

APIs return promises. Errors include PERMISSION_DENIED, RATE_LIMITED, SESSION_EXPIRED, STORAGE_FAILURE, INVALID_ARGUMENT, METHOD_NOT_FOUND, NOT_FOREGROUND; transport may return TIMEOUT, HOST_UNAVAILABLE or CLOSED. Show real connection state during Core reconnects. Do not replay writes automatically. Limits: one marine.snapshot per second, 20 total requests per second, and five writes per second shared by storage and system controls. Requests including the envelope are limited to 96 KiB; larger requests reject with PAYLOAD_TOO_LARGE.
