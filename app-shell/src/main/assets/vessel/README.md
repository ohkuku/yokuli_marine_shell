# Yokuli 通用单体帆船 · 1.0.0

`yokuli-sloop.glb` 是随应用离线打包的原创程序几何模型。船体和装具由
`scripts/assets/generate_vessel_model.py` 构建，没有导入第三方网格、贴图、字体或在线资源。

它是数据入口的语义船体，不是用户实船的 CAD，也不代表传感器的实际安装位置、船长、吃水、帆况或船型参数。静态帆型是模型的一部分，不是当前风力的观测或模拟。

## 重建

在仓库根目录执行：

```sh
python3 scripts/assets/generate_vessel_model.py
```

只需要 Python 3 标准库，输出直接写入本目录。生成器使用固定几何参数，不下载内容、不依赖随机数。资产采用 glTF 2.0 二进制格式；几何、法线、索引和 PBR 材质全部内嵌，没有纹理依赖。当前模型含 17,456 个三角形，文件大小 500,076 字节；这是资产规模，不是设备性能承诺。

## 坐标与语义

右手坐标系，`X` 为右舷，`Y` 为上方，`Z` 为船艏。根节点位于船体中心轴的水线平面，水线是 `Y = 0`。模型长度约 4 个示意单位；船艏 `Z = 2`、船艉 `Z ≈ -1.9`、桅杆顶 `Y = 3.8`、龙骨底 `Y = -1.2`。

| 节点 | 含义 / 原始根坐标 |
| --- | --- |
| `yokuli-sloop` | 根节点；无隐式坐标变换 |
| `hull` | 光滑船壳 |
| `mast` | 桅杆、横桁、吊杆 |
| `keel` | 有厚度的翼形龙骨和底部压载体 |
| `bow` | 船艏语义节点 `(0, 0.55, 2.0)` |
| `port` / `starboard` | 两舷护栏、舷侧饰线与位置灯外壳 |
| `hotspot:wind` | 桅杆上方 `(0, 3.8, 0.19)` |
| `hotspot:position` | 船体 `(0, 0.36, -0.1)` |
| `hotspot:heading` | 船艏 `(0, 0.55, 1.86)` |
| `hotspot:depth` | 龙骨下方 `(0, -1.2, -0.06)` |
| `hotspot:attitude` | 横向船体标记 `(0.63, 0.32, -0.7)` |

`hotspot:*` 和 `bow` 为没有网格的稳定语义节点。UI 标签使用语义 ID；不要绑定三角形编号。若渲染宿主对模型进行了归一化，标签投影必须使用相同的根节点变换。相机变换和模型姿态变换不改变数据的坐标定义。

模型使用深蓝船壳、浅色甲板、暖白织物、木质座板和低反射金属。双面帆采用不透明材质，避免移动设备上透明排序导致帆片错误遮挡；背面仍可见。所有数值、数据来源、状态和操作由应用显示，不烘焙在资产中。
