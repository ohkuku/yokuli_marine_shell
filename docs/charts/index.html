用于重新编译或整理。日常使用优先选择上方已准备好的资料包。

下载后，就在你的图册里。

  1. 01

    选择资料

    每个包明确列出海图、航行数据或三维内容。没有海图的包也可以为准星查询与规划提供资料。

  2. 02

    保存到手机

    应用内下载会保存到 Yokuli OS Documents → Chart Packages → 地区。网页下载位置由你的浏览器决定。

  3. 03

    在图册中使用

    打开下载好的 .yklpkg，完整导入后在图册选用。下载不会自动替换你正在使用的资料。
