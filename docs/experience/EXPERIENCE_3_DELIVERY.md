# 0.5.0-experience.3 交付记录

日期：2026-09-17。目标分支 `codex/yokuli-os-rebuild`。本轮以当前 WP Shell 为基础重整应用行为，保留原构建与 API Key 管理。不是旧 anchor UI 的复制，也不是全新独立项目。

## 实现

- **地图与海图库**：地理标记、测距、路线、圈和范围在地图引擎中原生绘制；整数比例尺与准星操作分开摆放；收藏先在地图预览；明确文件夹、命名图层和文件的 CRUD/优先级。
- **系统**：全局航行会话、持久通知中心、实际任务截图、应用根入口与最近任务的不同恢复语义；应用顶部不放“返回 OS”，底部 Back 在应用根页回到桌面。修复连续返回穿透、通知覆盖截图等边界。
- **应用**：日志的记录/时刻/历史/回放；地图为主的下锚流程、渐隐近期轨迹和实际累计停留范围；有业务意义的仪表可视化与个人排列；按应用选择磁贴样式和尺寸。
- **数据分享**：NMEA 与本机服务共用能力与来源选择；实际报文筛选、混合 XDR 字段过滤、逐客户端发送、同 IP 回送阻断、连接代次校验。来源设置由 NMEA 应用拥有。
- **统一体验**：共用字族、选择行、输入框、横滑、文字大小、单位和坐标格式；圆角/切口控件横向避让；应用列表的中英文索引一致。声纳采集和产品入口停用，历史数据保留。

| --- | --- |

## 检查中修复的回归

- 新版安装曾触发旧磁贴兼容目录缺少视觉声明的启动错误；已保留完整目录声明，仅在应用列表/搜索隐藏旧入口，重新安装启动通过。
- 个人仪表快速连选会被异步旧状态覆盖；改为完成时保存完整草稿，模拟器复验通过。
- 连续返回可能穿透应用首页、通知中心可能进入任务截图、NMEA 未保存草稿在切换后丢失；均已修正。
- 地图署名与底部提示、缩放控件与测距端点存在遮挡；调整覆盖物位置，保持底图视口尺寸。
- 窄系统栏的普通未读数会挤掉航行 REC；调整为航行、锚警会话优先，纳入最后构建。

## 需要真机继续确认的条件

- GNSS 长时间运行、厂商后台存活、报警音量和真实船载设备数据。
- 各厂商曲面屏、刘海及键盘行为；模拟器不能证明全部型号一致。
- Google 在线/卫星网络与全部用户 MBTiles 组合；已检查的自定义海图来自现有 QA 目录。
- 长时间锚泊的累计区域性能、NMEA 长时间多连接压力，不以短程检查替代海上运行。

海图磁贴底图为带捕获时间的快照；船位、速度等读数独立实时订阅。锚泊色块表示观测到的停留区域，不表示水深或安全水域。新通知中心只管理 Yokuli 内部通知，不读取 Android 其他应用通知。
