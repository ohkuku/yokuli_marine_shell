# 0.5.0-experience.4 · 2026-09-18

本轮针对用户 16 项反馈和 `Yokuli-implementation-review-2026-09-17.md` 的 19 项审查问题修改实际生产入口。审查文档作为待核查证据使用，其建议不替代用户要求。版本代码 7，包名和已有数据保持兼容。

## 用户可见变化

- 海图与守锚使用同一套地图控件。船位是小型船形，船头依真实新鲜船首向，COG 独立显示一分钟对地向量。选中收藏只显示地点详情，不移动地图或准星。
- 守锚按照“下锚 → 确认位置和范围 → 值守”组织。无轨迹不能估计、失败估计不显示问号候选；最近轨迹渐隐，累计色斑和警戒圈含义明确。
- 手机和 NMEA 读数保留最后观测与更新时间，关键实时方向继续区分时效。GGA+VTG、手机安装后的船首向与 NMEA/手机姿态遵循同一来源规则。
- 驾驶台突出航速、罗盘、帆航和姿态；每个趋势跟随选中读数，负风角左右舷对称，个人仪表保留拖排。磁贴草稿包含实际轮换设置。
- WP 大标题、Pivot、小字、单选、矩形开关和水平五点进度统一。消费者应用名称由 AppId 一处提供；稳定路径不改。
- 最近任务使用更清晰的真实截图和原始比例，上滑跟手、位移/速度决定关闭或弹回。底部通知键和根页 Back 回开始屏幕保留。

## 实际验证与范围

本地 Java 17 / Android 联合构建完成，`assembleStandaloneDebug` 成功，182 项回归零失败：Shell Engine 102、Contract 18、Compose 12、Legacy 25、Rebuild 25。实际结果见各模块的 `build/test-results`；联合构建执行 194 项 Gradle task（1 分 43 秒）。

模拟器已核对：地图拖动时原生地图 bounds 保持不变，准星读数紧贴底部命令；准星先由 Back 收起，根页 Back 返回开始屏幕；守锚共享大地图控件。最近任务短距离上拖后回弹，长距离上拖关闭当前卡片且保留另一个任务。

新增 `src/rebuildTest/java` 已接入实际构建，不引用已停用的旧 app-shell 测试。CI 新增当前模块回归任务；APK 构建独立进行，不恢复与当前生产模块无关的历史脚本。

本地候选 APK 用于离线图层和交互验收。带 Maps key 的交付由现有 GitHub Actions Secret 注入，未从旧 APK 取出或复制凭据。模拟器里的 QA 图层是明确标识的测试图块，不是真实导航海图。

仍需真机/船上验证：固定手机磁干扰与传感器校准、系统杀后台策略、长期锚泊告警与声音、真实 SAF provider 替换大文件、曲面屏边缘。旧守锚会话未保存当时失位超时参数，修改全局参数后回顾按新参数断线；本轮没有宣称历史策略完全复原。
