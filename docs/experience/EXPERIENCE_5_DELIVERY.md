# 0.5.0-experience.5 · 应用返回与数据中心

2026-09-18，versionCode 9。继续使用 marine_shell 的 Android 包名、构建、签名和密钥注入。

## 本轮产品变化

- 数据中心成为独立应用：统一呈现手机和各 NMEA 输入的读数、实际来源、更新时间与候选来源；逐项选择来源，管理手机定位和固定手机后的方向校准。
- 船联网只管理连接、收发、报文和发送内容。数据共享只管理本机监听服务、共享内容、客户端与写出记录。两端发布共用数据中心当前读数或明确的原始转发；原始转发继续保留输入身份与防回送规则。
- 不新建第二份业务配置。沿用 `VesselSettingsRepository`、`GpsDataSource`、`POSITION_CONNECTION` 和 `metricSourcePins`；统一写接口为 `setVesselMetricSource`。
- 旧的手机专用输出不被静默替换。编辑器解释其旧语义，用户明确改用数据中心并保存后才改变输出。
- A 的具体页面打开 B 的对象页，Back 恢复 A 原页面；B 再深入内部页面，先返回 B。普通应用入口打开首页，最近任务恢复已有访问，Home 放弃当前跨应用调用链。
- 页面实例独立保留标签、滚动、对象选择和编辑草稿。船联网从编辑页返回后保留原来的实况/语句/路由标签；初次共享允许直接确认默认配置。
- 海图离场时保存该次访问的视野、准星、选中坐标、测距和预览；跨应用回来恢复原状态。旧页面的原生地图回调不能写入新页面；全局导航与航行记录继续运行。
- Pivot 标题与页面拖动进度同步平移、交叉改变文字强调。温启动与内部转场直接绘制页面；最近任务截图只用于任务卡，并与页面实例对应。
- 取消最近任务不会重复播放应用开场；历史截图缓存限制为 8 张、32 MiB，淘汰图片不丢弃页面逻辑状态。已绘制的当前页在转场中仍可处理自己的 Back，不等待动画结束后才响应。
- 键位维持左侧 Back（长按最近任务）、中间 Home、右侧通知；没有恢复顶部下拉通知手势。
