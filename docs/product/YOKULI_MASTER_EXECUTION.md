# Yokuli OS · 自查、系统接入与通知实施主规则

本文件合并用户于 2026-09-25 提供的实施要求，作为继续同项工作的入口；它是要求，不是完成声明。通知专项的具体生产决策集中在 [通知中心契约](NOTIFICATION_CENTER_CONTRACT.md)，系统现状集中在 [运行时边界](../os/10-INPROCESS-SYSTEM-BOUNDARIES.md)。不维护另一份相互竞争的“最新方案”。

后续明确指示将生产视觉基线从 WP8 升级到 **Windows 10 Mobile / MDL2**；研究来源、适配取舍和共享组件入口集中在 [W10M 设计基线](WINDOWS_10_MOBILE_DESIGN.md)。历史 WP8 资料保留，但不能覆盖当前指示；视觉迁移不重写业务所有者、请求回执、来源或返回关系。后续用户明确保留经典应用开合/Home 翻转，当前实现将它与 W10M 控件和透明开始屏幕组合，不恢复旧式超大标题。

## 每轮实际工作

同时推进两条线：沿用户任务直接修复源码确认的问题；沿现有唯一运行时完成一个真实客户端已接入的系统能力闭环。当前通知中心专项包括消息/任务/警报分离、跟手关闭、四个快捷入口、独立任务卡、结构化消息、可清除与可见已读、通知返回链、持久化故障恢复。

执行顺序为：核对当前 HEAD 和生产入口 → 定位所有者及真实问题 → 修改业务和 UI → 替换实际调用方 → 同步权威指导文档。不要复读完整仓库后才开始修改，不在旧页、Preview、假数据或未调用接口中交付。现有正常能力与用户资料必须保留。

自查沿海图与对象详情互跳、导航与独立记录、守锚开始与恢复、来源丢失与修复、消息查看/清除/处理、AIS 跨视图对象、持久化失败与重新进入进行。优先解决数据错误、虚假成功、警报语义、资源重复和资料丢失，再处理任务走不通、导航混乱、通知交互及接入障碍。没有源码或运行证据时不宣称已复现，也不以大范围重写掩盖不确定性。

## 轻量功能与对象操作（experience.19）

- 地点先在海图同一场景中预览，普通单点前往直接展示几何路径，多点才需要起点选择。摘要、完整详情与跨应用调用保留对象 ID 和来路；修复来源后返回原预览。
- `TripRuntime.captureMoment` 在点击入口捕获所属航程、时刻和规范数据快照，先提交捕获日志及原事件表，再允许补名称、类型、文字。原数据和来源证据不可因编辑而重采；失败保留同 ID 重试。缺少合格位置为 null，暂停状态补记不等于继续采集。
- 来源替换由现有运行时准备候选、检查资格再采用，等待期间保留原来源。守锚运行时明确拒绝换源，不能把自动暂停当成便利步骤。固定手机以确认姿态为零点，旧版本校准不可假装已迁移。
- 新功能先利用现有对象摘要、来源修复、通知任务与分享入口，避免再造总控首页。一次只有一个对象展开完整详情，地图、三维相机及业务任务的所有者保持稳定。
- 本批实现附加文档的 A–D，并将航程分享收敛为三个用途。路线资料准备、最近时刻搜索与视图预设尚未作为新增能力交付；天气/潮汐需要真实提供方、许可与缓存链路，不创建空壳入口。

## 后续使用反馈（experience.20）

背景和透明磁贴应在设置及磁贴编辑中有明确入口，未选照片也可发现相关选项；预览与桌面共享实际绘制。全尺度单位、比例尺和尺寸的语义见 [总拓扑](OS_INTERFACE_TOPOLOGY.md#全尺度单位与系统偏好)。雷达场景不叠放系统边缘弧光或无必要的圆形信息按钮。姿态平滑只属于显示层，不能改变采集、来源与保护规则。详细动作及生命周期参数继续维护于现有 W10M 设计文档。

## 必须保持的系统方向

```text
Shell / 内置应用 / 获授权客户端
  → 窄领域客户端与能力描述
  → 进程内或 Binder 传输适配
  → 唯一领域运行时
  → 存储、GNSS、传感器、网络、文件、权限与通知适配
  → Android / AOSP
```

- Shell 拥有应用身份、访问栈、系统面板、输入、焦点与动画；UI 拥有相机、筛选、滚动和草稿；领域持有状态机、命令、持久化和恢复。平台与传输不能另造业务规则。
- 规范值与显示单位、UTC 与单调时间、来源身份与连接名称分别建模；不把缺测变成零、不因新字段或页面打开续期旧数据、不偷偷切换固定来源。Heading 不是 COG。
- 导航、记录、守锚和 AIS 分别具有独立生命周期。离开页面、Home、关闭通知和清除历史不改变运行任务；恢复页面不能重放 Start、Resume、Arm、Connect 或 Publish。
- 新功能需要实际读模型、类型化命令及对象 ID、结构化结果、稳定事件、能力、入口、返回关系、持久化与资源释放。纯契约不暴露 Context、Compose、OsStore、Room entity/DAO、控制器或 Job；当前本地兼容签名不等于新公共协议许可。
- 同一领域只能有一个活动写入者。IPC 需要真实客户端、服务、序列化、版本、调用者校验、初始快照、重连与死亡清理；枚举、空 AIDL、常量健康页不构成迁移。传输中断结果未知时查询原 requestId，不换 ID 自动重发副作用。
- 普通 APK 不抢 Android 顶边手势，不读其他应用通知，不以 AccessibilityService、全局 exported 或关闭 SELinux 模拟系统接管。

## 实施范围与权限

本轮不新增、改写或运行测试，不修改 CI、测试工具/门禁，不制作截图、录屏、测试或验收报告。允许必要的生产编译、源码引用与 manifest/依赖/资源检查；已有构建保护保留。取消验证材料不等于省略异常、持久化、迁移、权限、生命周期或释放。

常规可逆细节自行决定；不得覆盖无关修改、重置用户工作、自动停止保护、外发位置、清空资料、改设备权限、私自 push/发布/部署、付费建机、下载巨量 AOSP 或刷机。真实环境阻碍需如实保留，同时完成独立可做部分。
